# Hundo & Fiddy
Unified Movie Hundo + TV Fiddy PWA.

Included: shared blue/black home screen; 40-title onboarding on both sides; Top 100 / Top 50; Seen / Not seen / Not interested; 1–5 stars; persistent comments on onboarding and generated lists; History; carry-over chooser before regeneration; bundled Search & Add; unified backup/restore; per-side reset and full reset; versioned local data.

Important: this static GitHub Pages build searches its bundled catalogue and uses a local recommendation scorer. Internet-wide title search and true AI semantic interpretation of comments require an external catalogue/API plus AI/backend. Raw comments and history are preserved so that upgrade can be added later without losing user data.
